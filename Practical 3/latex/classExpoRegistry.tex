\doxysubsection{Detailed Description}
Central facade, factory, and lookup registry for managing the entire expo hierarchy. 

Encapsulates component creation, map generation, tree printing, component lookup via std\+::unordered\+\_\+map, relocation wrapper methods, visitor management, and signal transmission initiation.
